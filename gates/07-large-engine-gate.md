# 大型引擎与实时系统门禁

## 必须提交

- Runtime/Editor/Tools 分层
- 模块和插件依赖图
- 内存和资源所有权
- Job System/线程模型
- 帧和 GPU 预算
- 资产导入和派生资源管线
- 反射/序列化/迁移
- 输入、物理、音频、动画和网络边界
- Debug/Development/Shipping 构建
- 崩溃、设备丢失和恢复方案

## 检查

- 空项目能启动并运行最小场景？
- 资产能导入、保存、重开和重新导入？
- 设备丢失、插件崩溃和资源缺失可恢复？
- 实时路径是否有无界分配、锁和同步等待？
- 编辑器能力是否泄漏进 Shipping？
- 回放、存档和网络版本是否明确？

## 阻塞条件

- Runtime 依赖 Editor
- 线程/资源所有权不明确
- 帧预算没有测量
- 热重载、设备丢失或插件失败会直接崩溃且无恢复
- Shipping 构建无法从干净环境生成
