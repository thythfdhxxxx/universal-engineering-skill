# Changelog

## 1.3.0 - 2026-09-28

- Expanded automatic file-tree planning with file category, owner, dependency, lifecycle,
  monorepo, resource, migration, generated-file and registration rules.
- Added synchronization checks for build, test, schema, plugin, packaging and documentation
  consumers when files are created, moved or deleted.
- Expanded the file-tree template with change actions, single-source ownership and generator
  provenance fields.

## 1.2.0 - 2026-09-28

- Added mandatory project file-tree and file-ownership planning before implementation.
- Added file placement rules for source, tests, configuration, schemas, tools, scripts,
  documentation, generated files and excluded secrets.
- Added a reusable file-tree and ownership checklist template.

## 1.1.0 - 2026-09-26

- Added the AI execution protocol and explicit stop/ask/complete rules.
- Added project profile detection and project-specific gate concepts.
- Added toolchain gate adapter guidance and portable evidence validation.
- Added quality maturity scoring and machine-readable assessment support.
- Added Skill version governance and target software version governance.
- Added migration, compatibility, deprecation and multi-AI adapter guidance.

## 1.0.0

- Initial universal engineering Skill with requirements, architecture, implementation,
  UI, performance, security, testing, release, engine, AI and delivery guidance.
